# Регламент ведения журнала работы с ИИ (ai-log)

Настоящий навык регламентирует стандарты ведения журнала совместной работы студента и ИИ-ассистентов в рамках учебных проектов.

---

## 1. Назначение и файлы

- **`AI_LOG.md`** — основной документ отчёта в формате Markdown для проверки преподавателем.
- **`js/ai-log-data.js`** — синхронизированная структура данных на JavaScript, питающая интерактивный раздел «Как создавался сайт» без использования внешних API и `fetch`.

Оба файла должны быть строго согласованы по содержанию.

---

## 2. Структура записи о шаге

Каждый завершённый смысловой этап разработки (шаг) фиксируется в формате:

```markdown
### Шаг N. Название этапа
- **Модель**: Точное наименование используемой модели (например, Claude Opus 4.6 (Thinking), Gemini 3.8 Flash (High), GPT-OSS 120B (Medium))
- **Хотели**: Чёткая формулировка задачи (какой результат планировалось получить)
- **Получили**: Фактический результат (созданные/изменённые файлы, реализованная логика, объём кода)
- **Поправили**: Что потребовалось исправить вручную или дополнительными промтами (если ничего — прочерк «—»)
- **Оценка**: ✅ хорошо / ⚠️ плохо — краткое обоснование оценки
- **Значимый момент**: Только ключевые события: обнаруженная ошибка, находка, смена архитектурного решения или обход ограничений (если нет — пункт опускается)
```

---

## 3. Правила фиксации

1. **Достоверность**: Запрещено выдумывать факты, генерировать «воду» и приукрашивать результаты. Фиксируются только реальные действия.
2. **Без микро-логов**: Не фиксируются тривиальные опечатки, отступы или форматирование. Логируются законченные функциональные шаги.
3. **Учёт смены моделей**: Если задача выполнялась разными языковыми моделями, в поле `Модель` обязательно фиксируется фактическая модель каждого шага.
4. **Синхронизация**: При обновлении `AI_LOG.md` параллельно дополняется массив `steps` и объект `models` в `js/ai-log-data.js`.

---

## 4. Итоговый раздел (Summary)

По завершении всех этапов в конце журнала и в объекте `AI_LOG_DATA.summary` формируется итоговая рефлексия по 4 пунктам:

- **Чему научился**: Освоенные технологии, паттерны и концепции в процессе решения задачи.
- **Где ИИ помог**: Рутинные и сложные задачи, где использование модели дало наибольшую эффективность.
- **Где ИИ ошибался / потребовал доработки**: Ошибки генерации, несоответствие стандартам, недочёты вёрстки или логики.
- **Что пришлось проверять руками / тестами**: Аспекты, потребовавшие инструментальной верификации (браузерные тесты, доступность, адаптивность, безопасность).
