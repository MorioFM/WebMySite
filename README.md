# Портфолио — Ярослав (Atlix_TT)

Одностраничный сайт-портфолио на чистом HTML, CSS и JavaScript.  
Учебная работа, УРСЭИ, специальность «Прикладная информатика».

## Как запустить

1. Убедитесь, что установлен Python 3.
2. Откройте терминал в папке проекта.
3. Запустите локальный сервер:

```bash
python -m http.server 8000
```

4. Откройте в браузере: [http://localhost:8000](http://localhost:8000)

> **Примечание:** можно просто открыть `index.html` в браузере, но для корректной работы скриншотов с кириллическими именами файлов рекомендуется использовать локальный сервер.
